# Self-hosted fonts

Inter (400-800), Work Sans (300-700) and Instrument Serif (regular/italic) WOFF2 files were downloaded from Google Fonts on 2026-10-22. All returned language subsets are retained with their original unicode ranges. `src/styles/fonts.css` uses `font-display: swap` and Vite fingerprints the font files. The initial shell preloads only Latin Inter.

Source stylesheet: https://fonts.googleapis.com/css2?family=Inter:wght@400..800&family=Instrument+Serif:ital@0;1&family=Work+Sans:wght@300..700&display=swap

The adjacent per-family SIL Open Font License files are from https://github.com/google/fonts/tree/main/ofl. Font bytes are unmodified.
