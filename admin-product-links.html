Amazon Associates Compliant API Spec
Amazon Associates Compliance (updated April 14 2026):
  • No link cloaking or redirects — Amazon affiliate URLs must be direct amazon.com links. No /go/ style redirects or URL shorteners.
  • Affiliate tag — always append &tag=oxsteed-20 to every Amazon buy URL.
  • Disclosure — the app automatically shows "(paid link)" next to each affiliate link and "As an Amazon Associate, OxSteed earns from qualifying purchases." in every guide view. Do not remove these from the app code.
  • Own inventory — set link_type = own_inventory for OxSteed-stocked items. No disclosure required; the app renders "Shop OxSteed" instead of "Buy".
  • Register new platforms — update your Amazon Associates account whenever OxSteed launches a new platform (website, new app, etc.).

Backend API Reference · /api/learn/product-links

GET /api/learn/product-links
Fetched by the iOS app on every refresh. Returns all active overrides. No auth required.
{
  "products": [
    {
      "id": "uuid",
      "guide_id": "fix-leaky-faucet",    // null = applies to ALL guides with matching tool_name
      "tool_name": "Adjustable wrench",
      "link_type": "amazon_affiliate",    // amazon_affiliate | own_inventory | partner | rental
      "buy_url": "https://www.amazon.com/s?k=adjustable+wrench&tag=oxsteed-20",
      "rent_url": "/tool-rentals?category=hand-tools",
      "affiliate_tag": "oxsteed-20",
      "is_active": true
    }
  ]
}
GET /api/admin/learn/product-links
Admin — returns all links (active + inactive). Requires admin auth.
POST /api/admin/learn/product-links
Create a new product link override.
{
  "guide_id":      "fix-leaky-faucet",   // optional — omit for global scope
  "tool_name":     "Adjustable wrench",  // must match catalog tool name (case-insensitive)
  "link_type":     "amazon_affiliate",
  "buy_url":       "https://www.amazon.com/s?k=adjustable+wrench&tag=oxsteed-20",
  "rent_url":      "/tool-rentals?category=hand-tools",
  "affiliate_tag": "oxsteed-20",
  "is_active":     true
}
PUT /api/admin/learn/product-links/:id
Update any field. Partial updates supported.
DELETE /api/admin/learn/product-links/:id
Soft-delete (sets is_active = false). Hard-delete with ?permanent=true.
-- Suggested Postgres schema
CREATE TABLE learn_product_links (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  guide_id     TEXT,          -- NULL = global scope
  tool_name    TEXT NOT NULL,
  link_type    TEXT NOT NULL CHECK (link_type IN ('amazon_affiliate','own_inventory','partner','rental')),
  buy_url      TEXT,
  rent_url     TEXT,
  affiliate_tag TEXT,         -- e.g. 'oxsteed-20'
  is_active    BOOLEAN NOT NULL DEFAULT TRUE,
  created_at   TIMESTAMPTZ DEFAULT now(),
  updated_at   TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX ON learn_product_links (tool_name);
CREATE INDEX ON learn_product_links (guide_id) WHERE guide_id IS NOT NULL;
