✅ Validation Rules

📝 Title & Description

  • Title: ≥10 characters (trimmed)
  • Description: ≥50 characters (trimmed)
  • Both required

📍 Location

  • City: Required
  • Country: Required
  • State/ZIP: Optional
  • Lat/Lng: Auto-geocoded from city

💰 Budget

  • Type: 'fixed', 'hourly', or 'open'
  • Fixed: min = max amount
  • Hourly: min rate specified
  • Open: null amounts

🎥 Media Files

  • Max 10 files
  • Max 10MB per file
  • Allowed: jpg, png, pdf, mp4, webm, etc
  • Magic-byte validated (content sniffing)

🛠️ Requirements

  • License type optional
  • Insurance min $ optional
  • Background check optional
  • Skills (max 20) optional

👤 Preferred Helper

  • Helper ID optional
  • Helper name optional
  • Used for direct booking flow
  • Not enforced (hint only)
🗄️ Database Schema (jobs table)

Identity & Ownership

  • id: UUID (primary key)
  • client_id: UUID (poster)
  • assigned_helper_id: UUID (worker)

Job Content

  • title: VARCHAR(255)
  • description: TEXT
  • category_name: VARCHAR(100)
  • notes: TEXT

Location (PostGIS)

  • location_city: VARCHAR(100)
  • location_state: VARCHAR(50)
  • location_zip: VARCHAR(20)
  • location_country: VARCHAR(100)
  • location_point: GEOGRAPHY(Point)

Budget & Payment

  • budget_type: 'fixed', 'hourly', 'open'
  • budget_min: NUMERIC(10,2)
  • budget_max: NUMERIC(10,2)
  • urgency: 'flexible', 'soon', 'asap'

Requirements & Skills

  • requirements: JSONB (array)
  • required_skills: JSONB (array)
  • skill_ids: INT[] (for filtering)

Media & Metadata

  • media_urls: TEXT[] (S3 URLs)
  • status: 'published' (enum)
  • expires_at: TIMESTAMPTZ (+30 days)
  • created_at, updated_at
